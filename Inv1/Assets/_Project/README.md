# Тестовое задание 1: «Магазин и инвентарь»

Прототип магазина с инвентарём на Unity 6 (uGUI + TextMeshPro). Баланс и покупки
сохраняются в JSON-файл между сессиями.

## Как запустить

1. Открыть проект в Unity **6000.2.6f2**.
2. Открыть сцену `Assets/Scenes/Main.unity` и нажать Play.

## Сценарий

- Две вкладки: **Магазин** и **Инвентарь** (переключение кнопками под шапкой).
- В магазине — 12 предметов с ценой; у игрока стартовый баланс **500 монет**.
- Клик по «Купить» (или по карточке товара) списывает цену и добавляет предмет
  в инвентарь. Каждый предмет можно купить один раз.
- Кнопка блокируется и меняет надпись на «НЕ ХВАТАЕТ», если валюты недостаточно;
  купленный предмет помечается «КУПЛЕНО».
- Баланс анимированно «пересчитывается», карточка товара пульсирует при покупке,
  новая карточка инвентаря появляется с эффектом.
- После перезапуска приложения баланс и состав инвентаря полностью
  восстанавливаются из сохранения.

## Сохранение

- Формат — JSON, файл `shop_save.json` в `Application.persistentDataPath`
  (на Windows: `%USERPROFILE%\AppData\LocalLow/DefaultCompany/Inv1`).
- Сохранение выполняется при каждой покупке, при закрытии приложения
  (`OnApplicationQuit`), потере фокуса (`OnApplicationFocus`) и паузе
  (`OnApplicationPause`, актуально для мобильных).
- `PlayerPrefs` для игровых данных не используется.

## Структура

```
Assets/_Project/
├── Art/               # RoundRect-спрайт (9-slice), сгенерированный шрифт Segoe UI SDF
│   └── Icons/         # процедурные иконки предметов (PNG)
├── Items/             # 12 ассетов ScriptableObject ItemData
├── Prefabs/           # ShopItemWidget, InventoryItemWidget
└── Scripts/
    ├── Runtime/
    │   ├── ItemData.cs            # SO: id, название, описание, цена, иконка
    │   ├── PlayerState.cs         # модель: баланс + купленные ID, события
    │   ├── SaveSystem.cs          # загрузка/сохранение JSON
    │   ├── ShopManager.cs         # оркестрация: списки, покупки, вкладки, сейвы
    │   ├── ShopItemWidget.cs      # карточка товара (заполняется из SO в коде)
    │   ├── InventoryItemWidget.cs # карточка инвентаря
    │   ├── BalanceLabel.cs        # анимация счёта баланса
    │   └── TabButton.cs           # вкладка с состояниями
    └── Editor/
        ├── PrototypeBuilder.cs    # генерация ассетов, префабов и сцены (меню Prototype)
        └── IconPainter.cs         # процедурная отрисовка иконок (SDF)
```

## Технические детали

- Canvas: `Screen Space — Overlay`, `CanvasScaler → Scale With Screen Size`,
  референс 1920×1080, match 0.5.
- Списки магазина и инвентаря — `ScrollRect` + `Viewport (RectMask2D)`,
  контент с `Vertical Layout Group` + `ContentSizeFitter (Preferred Size)`;
  карточки — префабы, инстанцируются кодом и заполняются данными из
  ScriptableObject’ов.
- Шрифт UI — запечённый SDF-атлас «Segoe UI» со статичным набором глифов
  (кириллица + латиница), поэтому текст работает и в билде без шрифтов ОС.
- Иконки, скруглённые спрайты и сам шрифт генерируются редакторским скриптом
  `Prototype/Сгенерировать всё` — проект самодостаточен без внешних ассетов.

## Проверка сохранения в редакторе

Состояние пишется и при выходе из Play Mode (через `OnApplicationFocus`/`OnApplicationQuit`).
Чтобы сбросить прогресс — удалите `shop_save.json` из `Application.persistentDataPath`.
